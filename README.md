# Анализ эффективности маркетинговых кампаний
**Контекст:**
Автодилер хочет понять, какие маркетинговые кампании в интернете работают лучше всего. Компания наняла консалтинговую IT-компанию, чтобы ответить на вопросы:
- Какие маркетинговые кампании работают лучше всего?
- Какие модели продаются лучше всего через интернет?
- Какая общая выручка и маржа за период, и какие модели выгоднее продавать через интернет?

В рамках пилотного проекта были взяты ограниченные данные по двум маркам - BMW и Mercedes. Данные из Google Analytics и CRM были объединены по Client ID, чтобы отследить путь клиента от заявки до продажи.

Задача: объединить данные из Google Analytics и CRM, построить дашборд и ответить на вопросы клиента о том, какие кампании приводят к конверсиям и продажам, какие модели продаются лучше всего через интернет.

Инструмент - **PowerBI** (подготовка данных, DAX, визуализация) 

# Структура данных
Данные собраны из нескольких источников и объединены в реляционную модель по **идентификатору клиента**.

**Таблицы:**
- **Данные из CRM** - информация о клиентах: город, приход в офис продаж, продажа, просчёт стоимости объекта.
- **Маркетинговые данные** - данные о поведении на сайте: браузер, город, дата, девайс, домен сайта, источник перехода, конверсия, марка и модель.
- **Справочник** - справочная информация: валюта, маржинальность, марка, модель, цена.
- **Динамика активов** - данные об активах по бизнес-сегментам и месяцам.
- **Идентификатор клиента** - таблица-мост, связывающая CRM и маркетинговые данные.

**Связи:**
- «Данные из CRM» и «Маркетинговые данные» связаны с таблицей «Идентификатор клиента» по полю *Идентификатор клиента*.
- «Маркетинговые данные» связаны со «Справочником» - это позволяет подтягивать марку, модель и цену.

# Подготовка данных
Перед анализом данных, была произведена очистка данных:
- приведены типы данных (текст в число, категориальные поля приведены к единому регистру)
- удалены лишние пробелы
- исправлены опечатки
- синонимы объединены
- для сумм и конверсий настроены меры DAX
- настроены связи между таблицами в модели данных

# Визуализация
Для анализа конверсий были построены визуальные элементы, показывающие ключевые срезы: общее количество конверсий выведено в виде *карточки*, распределение по городам, маркам и браузерам - в виде *линейчатых диаграмм*, динамика по дням - в виде *графика*, а распределение по девайсам - в виде *кольцевой диаграммы*. Из визуализации по городам было убрано значение «(not set)», чтобы не искажать географическую картину.

Для географического анализа были построены две *карты*: обычная карта по топ-10 городам по количеству продаж и ArcGIS-карта с полным анализом продаж по стране. Это дало возможность увидеть распределение продаж по регионам и выделить ключевые города.

Для анализа пути клиента была построена *матрица с воронкой продаж* по регионам, городам и маркам. В ней настроено условное форматирование: гистограмма для столбца с конверсиями и светофор для столбца продаж. Это позволило быстро выделять регионы и марки с наибольшими и наименьшими показателями.

К карте была добавлена *подсказка в виде полной и нативной воронки продаж* из пяти шагов с нарастающей прозрачностью. Также выполнена *декомпозиция продаж* по пяти параметрам и построена диаграмма дерева для марок и моделей авто. Эти элементы позволили углубить анализ и показать структуру продаж в разрезе марок и моделей.

Дашборд сделан **интерактивным**: пользователь может самостоятельно настраивать отображение данных с помощью фильтров и срезов, а также перемещаться между страницами "Анализ конверсий" и "Анализ продаж" при помощи кнопок перехода. Такая навигация позволяет пользователю последовательно изучать данные: от конверсий к продажам, не теряя контекст.

# Результаты
В ходе анализа удалось установить:

**По конверсиям:**
1. Общее количество конверсий за период - 33 тыс.
2. Марка **Mercedes лидирует** по количеству конверсий: 17 175 против 15 858 у BMW.
3. Большинство конверсий приходит из **Краснодара** (18 246), далее следуют Сочи, Ставрополь, Ростов-на-Дону и Москва.
4. По устройствам **преобладают мобильные** (60%), на десктоп приходится 37%, на планшеты - 3%.
5. Среди браузеров **лидирует Chrome** (17 399 конверсий), далее - YaBrowser и Safari.

**По продажам:**
1. Общее количество продаж - 3 952, из них Mercedes - 2 022, BMW - 1 930.
2. Лидер по продажам - Краснодарский край (2 929 продаж), значительно опережающий другие регионы.
3. Среди моделей BMW чаще всего продаются x1 (131), 318 (100), x5 (58).
4. Среди моделей Mercedes - e220 и gls.
